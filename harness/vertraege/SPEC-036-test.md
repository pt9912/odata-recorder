# SPEC-036 — Unit-Tests (`make test`)

**Werkzeug:** `make test`.

**Festlegung:** Unit-Tests für Domain, Matching, Query-Interpreter und CRUD.

**Stand:** entsteht mit dem Slice, der den Code liefert.

**Grenze:** Prüft kein Zusammenspiel mit Upstream oder Datenbank; das tun `make test-integration` und die Verträge `SPEC-037` und `SPEC-042`.
