# SPEC-101 — Lint-Profil (`make lint-profil`)

**Werkzeug:** `make lint-profil`.

**Festlegung:** Lint-Profil `.golangci.yml`: Schema-Prüfung mit golangci-lint v2; Unterdrückungen nur im Profil mit `# Why:`.

**Stand:** vorhanden für die Schema-Prüfung; die Prüfung des Codes entsteht mit dem Slice, der den Code liefert.

**Grenze:** Die Schema-Prüfung prüft kein Code.
