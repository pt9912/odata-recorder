**Zählprüfung nachgerechnet** (eigenes Verfahren, nicht der Generator und nicht der Code des Lesers): Nachbarn einer Zeichenkette der Länge n mit L Läufen gleicher Bytes: Löschen L, Ersetzen 255·n, Einfügen 256·(n+1) − n (die Längen n−1, n, n+1 überschneiden sich nicht, ein Ersetzen durch dasselbe Byte ist die Eingabe selbst). `127.0.0.1` und `localhost` (n = 9, L = 9): 4855 ✓; mit `:8081` (n = 14, L = 14): 7410 ✓; `[::1]` (n = 5, L = 4): 2810 ✓; `[::1]:8081` (n = 10, L = 9): 5365 ✓; Summe 4855 + 7410 + 2810 + 5365 + 4855 + 7410 = **32705** ✓.
