keine Reihenfolge von Terminen (siehe
Baseline-Regelwerk `modul-06-roadmap.md`).

**Lesart:** Eine Welle steht hier, wenn ihr Trigger eingetreten ist oder ihr erster Slice gestartet ist; sonst steht sie unter *Nächste Wellen* mit Link auf ihre Datei. Bei einer Welle mit gestaffeltem Start (`welle-sensoren`, `welle-mock`) zählt der Trigger ihres ersten Teils. Ein einzelner Slice, der vor dem Trigger seiner Welle starten darf, weil kein Code der Vorgänger-Welle fehlt, ist eine Ausnahme je Slice (Zusatz in der Welle-Datei, Spalte *Trigger* unten) und verschiebt die Welle nicht; so steht `welle-betrieb` unter *Nächste Wellen*, obwohl `slice-audit-log` (Linie D) läuft. `welle-benutzerhandbuch` steht hier, weil mit dem Gerüst ihr erster Slice läuft: Der Trigger der Welle (Werkzeug für die Marke) ist für diesen Zweck erfüllt, weil das Werkzeug in `main` lauffähig ist.
