# Eine Zusage über Ziffern gilt für jede Ziffer an jeder Stelle, die Fixtures decken einzelne Anzahlen

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Der Vertrag nennt eine Zahl als Dezimalfolge (jede Ziffer an Einer-, Zehner- und Hunderterstelle); der Fänger führt einzelne Anzahlen, nicht die Menge der Ziffern, und eine Mutation, die eine Ziffer abweist, bleibt grün. Der Plan hatte die Klasse nicht als Menge genannt. Nahe an `suite-ohne-generator-fuer-klassen-der-spezifikation`, das denselben Vorgang als Beleg trägt.
