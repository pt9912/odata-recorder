# Eine Prüfung steht an zwei Stellen, und die zweite ist ersetzbar, ohne dass etwas rot wird

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Dieselbe Regel steht im Code an zwei Stellen; die zweite Prüfung hat keine Wirkung, die die erste nicht schon hätte, und kein Test wird rot, wenn man sie ersetzt oder entfernt. Sie ist tote Absicherung und trägt eine Zusage, die kein Fänger kennt.
