# Ein akzeptiertes Negativ steht ohne seine Folge da

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Vertrag nimmt einen Fall bewusst ungeprüft hin (*Ungeprüft*, akzeptiertes Negativ) und begründet ihn mit einem Vorgänger, dessen Lage anders ist; die Folge im eigenen Fall steht nirgends, bis eine Prüfrunde sie mit einer Probe zeigt.
