# Ein Befund an eine Rolle ohne Artefakt hat keine Spur im Repo

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Prüfrunde übergibt einen Befund an eine Rolle, die im Repo kein eigenes Artefakt führt (Validator, Owner, Auftraggeber); kein Plan, keine Welle und kein Register nimmt ihn auf, und er bleibt nur im Bericht stehen, bis eine spätere Runde nach ihm sucht.
