**Fund:** Drei Review-Runden in Folge fanden an der Klasse „Backslash an jeder Stelle der Grammatik“ (`SPEC-285` Nr. 2) je eine Achse, die der Fix der Vorrunde nicht führte, weil die Menge aus den Beispielen des Befunds gebildet war: Runde 2 die Folgen von Backslashes im Paar eines fremden Elements (EA4, dann EA5 bis EA7), Runde 3 den Backslash hinter dem Schlusszeichen eines Paares (S1, S2, C1 bis C5), Runde 4 das Zeichen vor der Folge und den Kontext des Paares (zwölf Mutationen, sieben davon im Paket grün).
