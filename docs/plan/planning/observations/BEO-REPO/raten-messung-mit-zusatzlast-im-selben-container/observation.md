# Die Rate eines Zeit-Fängers wird mit Zusatzlast im selben Container gemessen

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Die Messung der Rate eines Zeit-Fängers (Frist, Wartegrenze) erzeugt ihre Zusatzlast als Rechenschleifen im selben Container wie den Test; die Last des Hosts anderer Linien läuft zugleich. Nachbar von `rate-ohne-detektor-schwankt-mit-der-last`.
