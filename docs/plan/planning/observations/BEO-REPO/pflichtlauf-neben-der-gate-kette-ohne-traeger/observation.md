# Ein Ziel neben der Gate-Kette bekommt einen Pflichtlauf im Text, aber keinen Träger

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Ziel, das wegen seiner Laufzeit nicht an `GATE_CHECKS` hängt (Vorbild `make gegenproben`), bekommt als Ausgleich einen Pflichtlauf vor der Closure einer Welle oder bei Änderungen an bestimmten Pfaden. Der Pflichtlauf steht als Rat in einem Plan; kein Sensor, kein Stempel und kein Command ruft das Ziel zu diesem Zeitpunkt. Ein Trigger ohne Wächter ist eine Absichtserklärung mit Verfallsdatum (Modul 6, Schritt 2 der Wellen-Closure).
