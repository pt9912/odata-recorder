# Der Plan hat einen Weg für das Verfehlen eines Zielwerts, aber keinen für einen Lauf ohne Messwert

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine DoD und ein Closure-Trigger verlangen eine Zahl und regeln allein den Fall, dass sie den Zielwert verfehlt (Carveout mit Folge-Slice). Liefert der Lauf keine Zahl, weil das Gemessene abbricht oder der Lauf ungültig ist, ist der Punkt weder erfüllt noch geregelt, und die Closure muss die DoD nachträglich ändern.
