# Eine Teil-Zusage hat Mutationen, die nur zusammen rot werden, und keine Fixture isoliert sie

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Zusage hat Teile (zweites Wort bei mehreren Leerzeichen), und mehrere Mutationen an ihnen bleiben zusammen grün, weil jede Fixture mehrere Teile zugleich führt. Der Fänger zählt erst, wenn jede Mutation für sich rot wird.
