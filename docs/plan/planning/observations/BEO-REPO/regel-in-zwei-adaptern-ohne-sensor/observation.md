# Dieselbe Regel steht in zwei Adaptern, und kein Sensor hält die Kopien gleich

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Zwei Adapter derselben Schicht führen dieselbe Regel als getrennt gepflegten Text, weil kein Adapter den anderen importieren darf; die Gleichheit steht als Aussage im Vertrag (*Ungeprüft*), ein Gate hält sie nicht. Weichen die Kopien ab, wird kein Test rot, bis ein Ende-zu-Ende-Fall sie zusammenführt.
