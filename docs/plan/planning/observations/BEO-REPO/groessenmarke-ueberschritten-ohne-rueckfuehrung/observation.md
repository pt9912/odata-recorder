# Ein Slice überschreitet seine Größenmarke, und die Rückführung greift nicht

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Slice überschreitet die Rückführungs-Marke aus §4 seines Plans (Summe aus `git diff --numstat`, `AGENTS.md` §3.14). Gemessen und entschieden wird, wenn Code und Tests fertig sind, und die Rückführung nach `next` unterbleibt, weil ein Schnitt dann nur Übergabe kostet oder die Teile einzeln nichts liefern; den Zuwachs tragen überwiegend Tests, Vertragstests und Fänger aus Review und Verifikation.
