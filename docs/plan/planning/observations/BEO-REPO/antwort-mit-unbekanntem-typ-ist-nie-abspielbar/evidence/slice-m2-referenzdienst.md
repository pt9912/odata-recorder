**Fund:** Der Architect las beim Start des Slice den Wortlaut von `SPEC-118` Nr. 3 und `SPEC-045` Zeile 3 und stellte fest, dass der Referenzdienst `/Products/$count` als `application/json` mit Body `{"count":N}` liefern muss, damit der M2-Test die Antwort abspielen kann (Fixture-Entscheidung, keine OData-Treue). Nicht am Code gemessen, nur am Wortlaut; der Implementer sieht es, wenn er die Fixture versuchsweise auf `text/plain` stellt. Offene Frage an den User und den Architect: Ist es gewollt, dass die echte Antwort auf `/$count` und `$value` nie abspielbar ist? Eine Spec-Änderung gehört nicht zu diesem Slice.
