# Die Zusage „meldet jede neue Verzweigung“ ist weiter als die Funktionsliste der Zählprüfung

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Zählprüfung der Verzweigungen (`go/parser`) liest eine feste Liste von Funktionen; sie ist eine Setzung, kein Aufruf-Graph. Der Plan sagt zu, sie melde „jede neue Verzweigung“, und meint nur die Funktionen der Liste: eine Verzweigung in einer Hilfsfunktion oder in einer nicht gelisteten Funktion meldet sie nicht. Der Wortlaut nennt die Funktionsliste (`AGENTS.md` §3.11), sonst ist die Zusage größer als der Fänger.
