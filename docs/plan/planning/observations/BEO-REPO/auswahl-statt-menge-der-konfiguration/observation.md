# Der Fänger einer Zusage über eine Konfiguration führt eine Auswahl der Regeln oder Module, nicht ihre Menge

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Zusage gilt für jede Regel oder jedes Modul einer Konfiguration („`file` und `structure` lesen `.wt/` nicht“, „die Module von `d-check` lesen `scan.ignore`“); der erste Fänger führt die Elemente, die dem Autor einfielen (13 Pfade ohne die erste Regel von `structure`, ein Modul von zehn gemessen), und eine Mutation an einem fehlenden Element bleibt grün. Nahe an `suite-ohne-generator-fuer-klassen-der-spezifikation` und `menge-ohne-ihre-positionen`: dort ist die Menge eine Klasse des Formats oder des Arguments, hier steht sie in einer Datei des Repos, die der Aufbau lesen kann.
