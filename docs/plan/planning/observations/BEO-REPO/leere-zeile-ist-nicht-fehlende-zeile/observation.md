# Die leere Zeile ist ein Element des Fängers, das die fehlende Zeile nicht ersetzt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Der Vertrag nennt eine Zeile mit einem Wert (Dezimalzahl von 0 bis 255); der Fänger führt `""` als fehlende Zeile, die leere Zeile als eigenes Element fehlt. Die Mutation, die die Prüfung auf die leere Zeichenkette entfernt, bleibt grün.
