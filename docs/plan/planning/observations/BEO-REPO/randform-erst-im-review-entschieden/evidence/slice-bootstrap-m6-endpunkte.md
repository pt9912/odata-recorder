**Vorgang:** slice-bootstrap-m6-endpunkte
**Fund:** Was die Diagnose für `SQLiteBusyTimeout` außerhalb der Grenzen des Ladens zeigt (nur über ein von Hand gebautes Literal erreichbar), war vor dem Code allein für den Wert 0 entschieden; das Raster führte die Zelle ohne diese Werte. Der Implementer gab die Werte über 2147483647 ms nach dem Code-Commit zurück, das Review fand dazu die negativen Werte und den Testfall, der die Abweichung gegen `SPEC-300` Nr. 6 als Soll führte (F-2); der Architect entschied danach (Nr. 6 gilt der geprüften Konfiguration, *Ungeprüft* nennt die ganze Klasse). Zwei weitere Randformen desselben Slice standen vor dem Code fest (Rest unter 1 ms, leerer `AdminListen`). Beleg: Review `2026-11-26-slice-bootstrap-m6-endpunkte-review` (F-2), Plan `slice-bootstrap-m6-endpunkte` §3, §6.
