# Eine Randform eines neuen Vertrags entscheidet erst das Review

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Slice liefert einen neuen Vertrag (Kommando, Format, Gate), und sein §6 und die Spezifikation lassen Randformen offen (leeres Argument, Zusatzargument, nil-Writer); der Code entscheidet sie still, und erst das Review findet, dass weder Plan noch Vertrag sie nennen.
