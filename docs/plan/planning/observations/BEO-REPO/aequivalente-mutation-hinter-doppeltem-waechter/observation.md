# Eine Mutation bleibt grün, weil ein zweiter Wächter denselben Fehler fängt, und die Zeile der Tabelle nennt einen Einzel-Fänger

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Zwei Stellen im Code prüfen dasselbe (etwa UTF-8 in `artPruefer` und in `text`). Entfällt eine allein, ändert sich kein Verhalten; ein Fänger für sie allein existiert nicht. Die Zeile der Tabelle *Zusage · Fänger* sagt „Fänger“, obwohl nur das Paar fängt. Die Zeile braucht den Grund (zwei Wächter), die Folge im Betrieb je Wächter und den Fänger als Paar; sonst ist sie eine Zusage ohne Fänger (`AGENTS.md` §3.15). Verwandt, aber verschieden von `BEO-REPO/aequivalent-eingestuft-ohne-umzuordnende-eingabe` (dort fehlt die Eingabe, die den Mutanten trennt; hier fängt ein zweiter Wächter).
