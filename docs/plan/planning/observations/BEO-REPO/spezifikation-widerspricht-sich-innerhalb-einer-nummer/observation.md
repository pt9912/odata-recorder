# Eine Nummer der Spezifikation sagt in einem Satz das Gegenteil ihres Absatzes, der Code folgt dem Absatz

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Der Satz einer Nummer nennt eine Entscheidung (ein Lauf in der Form von V4, „der lesbar ist“, ist `wert`), ein Absatz derselben Nummer eine andere (die Form entscheidet, Rest und Bereiche sind nicht geprüft); der Plan und der Fänger folgen dem einen, der Code dem anderen, und erst das Review liest beide Stellen nebeneinander. Die Schärfung der Spezifikation vor dem Code prüft nicht jeden Satz einer Nummer gegen ihre übrigen. Nahe an `spezifikation-verbietet-den-antworttyp-die-sie-selbst-nennt`, das einen Widerspruch zwischen zwei Nummern trägt.
