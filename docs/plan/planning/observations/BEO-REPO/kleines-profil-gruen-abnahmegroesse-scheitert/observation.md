# Das kleine Profil eines Messwerkzeugs ist grün, und in der Größe der Anforderung scheitert das Produkt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Anforderung nennt eine Größe (Zahl der Daten, Rate, Speicher), und bis zum letzten Slice der Kette läuft das Produkt allein in kleinen Größen: in Tests mit wenigen Einträgen und im kurzen Profil des Werkzeugs. Eine Entscheidung im Vertrag, deren Kosten mit der Größe wachsen, wird mit Verweis auf die spätere Messung angenommen; erst der Lauf in voller Größe zeigt, dass das Produkt die Anforderung nicht trägt.
