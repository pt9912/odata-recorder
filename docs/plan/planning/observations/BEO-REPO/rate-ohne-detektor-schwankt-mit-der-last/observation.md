# Eine Rate ohne Detektor steht als Einzelzahl, obwohl sie mit der Last schwankt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Kommentar oder Plan nennt die Rate eines nebenläufigen Fängers, der nur mit Wahrscheinlichkeit rot wird, als eine Zahl aus einer Messreihe. Die Rate hängt von der Last des Hosts und vom Messenden ab; jede weitere Prüfrunde misst eine andere Zahl, und wer die Zahl als feste Größe liest, irrt um Punkte, ohne dass ein Fänger an ihr hängt.
