# Eine Allaussage im Vertrag über Beobachtbares ist falsch, und kein Fänger widerlegt sie

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Vertrag oder sein Plan sagt etwas über alle Fälle aus („kein Fall meldet zwei Gründe für einen Schlüssel“); keine Prüfung durchsucht die Fälle, und erst das Review findet einen Gegenfall im Code.
