**Vorgang:** slice-listener-tls
**Fund:** Die Zusage über das gelieferte Config (`SPEC-291` Nr. 5: es trägt die drei Felder und sonst nichts) ist eine Aussage über jedes Feld des Typs `tls.Config`; der Fänger nannte die zugesagten Felder als Positivliste, und sieben Mutationen an anderen Feldern (`KeyLogWriter`, `Time`, `CurvePreferences`, `PreferServerCipherSuites`, `VerifyConnection`, `Renegotiation`, `SessionTicketsDisabled`) blieben grün, 7 von 7 (Review F-4). Der Fix zählt jedes Feld per Reflexion (Menge C); dieselbe Bauart eine Ebene tiefer blieb offen: drei von sechs Feldern von `tls.Certificate` sind ungefangen (Verifikation V-2, Negativ 7). Beleg: `docs/reviews/2026-11-21-slice-listener-tls-review.md` (F-4), `docs/reviews/2026-11-21-slice-listener-tls-verifikation.md` (V-2) und Plan `slice-listener-tls` §3.
