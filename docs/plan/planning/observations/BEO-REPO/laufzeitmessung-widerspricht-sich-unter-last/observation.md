# Eine Laufzeitmessung auf dem geteilten Host widerspricht sich zwischen den Rollen

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Plan zieht aus einer Laufzeitmessung einen Gewinn oder Verlust; Implementer, Reviewer und Verifier messen denselben Satz unter wechselnder Last des Hosts und kommen auf Zahlen mit verschiedenem Vorzeichen. Die Streuung der Läufe ist größer als der Unterschied zwischen den Seiten, und ein Lauf je Seite beweist weder das eine noch das andere. Verwandt mit `rate-ohne-detektor-schwankt-mit-der-last` (dort die Rate eines Fängers, hier die Laufzeit).
