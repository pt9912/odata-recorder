# Eine Menge im Plan nennt Elemente oder Erwartungen, die der Test nicht führt, und der Plan folgt dem Test nicht

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Der Plan beschreibt eine Menge des Fängers (Elemente, Zahl, Erwartung je Element) und der Test führt eine andere: die Spalte *Erwartung* sagt einen Zustand, den der Test für ein Element nicht prüft, oder die Zählung des Plans gilt auf einer anderen Ebene als die des Tests. Der Fänger ist richtig, der Plan sagt mehr oder anderes zu; erst der Verifier liest beide gegeneinander.
