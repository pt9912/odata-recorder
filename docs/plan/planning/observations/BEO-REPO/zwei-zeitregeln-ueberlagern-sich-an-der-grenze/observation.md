# Zwei Regeln der Zeit wirken an derselben Grenze, und weder Vertrag noch Plan nennen ihren Vorrang

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Vertrag trägt zwei Regeln der Zeit (die Grenze eines Kontexts und das Warten auf offene Ströme); an der Grenze wirken sie zusammen, und der Code entscheidet den Vorrang, den kein Raster nennt. Die Menge ist das Produkt aus Ende des Binary, Ende des Kindes und Aufrufstelle.
