# Eine Berichtigung erreicht nicht jede Stelle, die dieselbe Aussage trägt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine normative Aussage (Statuswert, Reihenfolge, Lauf-Angabe, Zahl) steht an mehreren Stellen in Spezifikation, Sicht und Plänen. Ein Befund nennt eine oder zwei davon, die Berichtigung trifft genau die genannten, und die nächste Prüfrunde findet die übrigen im alten Wortlaut.
