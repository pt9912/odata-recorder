Der Zustand eines Slice ist das Verzeichnis, in dem seine Datei liegt; die Links der Tabelle nennen es. Die Pläne tragen ihre Start-Trigger mit Abhängigkeiten, und `plan-welle` gleicht sie beim Start gegen den Ist-Stand ab. Marken und Betriebsregeln setzt der Planner beim Start (`SPEC-128`).

**Pflicht Handbuch:** Jeder Slice, dessen Ergebnis ein Anwender am Binary sieht (neues Kommando, Konfigurationsschlüssel, Fehlercode, HTTP-Schnittstelle, Betriebsart), trägt in seiner DoD den Punkt „Handbuch-Kapitel im selben Slice nachgezogen (Ist-Zustand, belegt durch ein Beispiel als Datei gegen das gebaute Binary); das Kataloge-Gate ist grün“. Das Binary ändert sich in dieser Welle erst mit [`slice-bootstrap-m6`](open/slice-bootstrap-m6.md) (der Admin-Listener erreicht es vorher nicht): verbindlich trägt den Punkt dieser Slice (Endpunkte, `ADMIN_*`, Token, `ODR-E2101`), die übrigen Slices tragen ihn bedingt, nämlich nur, wenn sie einen Fehlercode, Schlüssel oder ein Kommando in den Katalog bringen. Kommandos über Start und Version hinaus liefert die Welle nicht (§6), also auch keinen Eintrag im Kommando-Katalog.
